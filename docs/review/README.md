# 점검 결과 (docs/review)

팀장이 모의 채점(Docker + E2E)과 휴대폰 화면 점검을 할 때마다 결과를 여기에 남긴다.

- `LATEST.md`: 가장 최근 점검. **모든 사람과 에이전트는 작업 전에 이 파일부터 읽는다.**
- `YYYY-MM-DD_HHMM.md`: 지난 점검 기록. 고치지 않는다.

## 에이전트가 하는 순서

1. `git pull --rebase origin main`
2. `docs/review/LATEST.md`에서 **내 담당(p1~p5) 줄**과 "지켜야 할 규칙"을 찾는다.
3. 내 담당 항목을 **먼저** 처리한다. 그다음 원래 하던 화면 작업을 한다.
4. 커밋 메시지에 처리한 항목 번호를 적는다. 예: `p1: review#1-3 프로필 로그아웃 버튼`
5. 내 담당이 아닌 문제를 발견하면 고치지 않고 사람에게 알린다. 팀장이 다음 점검에 넣는다.
6. 화면 점검표에서 내 화면 칸을 확인했으면 사람에게 알린다(체크는 팀장이 다음 점검에서 갱신).

## 팀장이 하는 순서

1. 브랜치들을 합쳐 모의 채점·화면 점검
2. 새 점검 파일 `YYYY-MM-DD_HHMM.md` 작성 → 같은 내용을 `LATEST.md`에 덮어쓰기
3. main에 push하고 단톡에 "main 갱신됨 · 점검 #N" 공지
